# HW-Triage-Bench

Benchmark for validation **failure-to-report** automation.

## Tasks

1. **Log classification** — assign failure signatures from heterogeneous validation logs
2. **Schematic localization** — map failures to component regions in PDF schematics
3. **Report generation** — produce structured diagnostic summary for design review

## Release checklist

- [ ] Synthetic + anonymized log corpus
- [ ] Open schematic PDF references (KiCad exports)
- [ ] Gold labels + report quality rubric
- [ ] Baseline harness (rules, RAG, agentic)
- [ ] Zenodo DOI for v1.0.0
